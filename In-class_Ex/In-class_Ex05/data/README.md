# In-Class Exercise 5 data

These files are the datasets distributed with the official ISSS626 In-Class Exercise 5 materials:

- `aspatial/Hunan_GDPPC.csv` contains annual county GDP per capita values from 2005 to 2021.
- `geospatial/Hunan.*` is the Hunan county boundary shapefile used to build the space-time cube and spatial weights.

Source: [ISSS626-AY2026-27Aug, In-Class Exercise 5 data](https://github.com/tskam/ISSS626-AY2026-27Aug/tree/master/In-class_Ex/In-class_Ex05/data), accessed 26 September 2026.
